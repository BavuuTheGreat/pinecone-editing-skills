# Editing automation: what changes for you

The Editing station now has an automatic helper, the editing factory. This page says what it changes for a member and
what it does not.

## What changes

1. **You drop a folder.** Put your footage in one folder. Give the folder a clear name, for example
   `2026-11-20 PineQuest <name>`. Put the folder in the factory inbox.
2. **You can add a note.** A file called `note.txt` in the folder helps. Write one fact on each line, for example
   `name: <name>` and `team: <team>`. Write names exactly. The factory never takes a name from speech.
3. **You wait for the proposal.** The factory looks at the footage. It writes a proposal: the type of reel, the hook line,
   the length and the music. It also lists what it does not know.
4. **You say yes or no.** Nothing is edited until the Editing manager approves the proposal. If something is wrong,
   say no and write why.
5. **The edit is made.** After your yes, the factory writes a full brief for the editing agent. The agent makes the reel
   with the same skills as before.

## What does not change

- A person reviews every reel before it is posted. You still upload it to the Marketing Planner for review.
- The reviewer's comments still go back to the editing agent, and the reel is fixed.
- The reel types and their style rules are the same.

## What is not automatic yet

- Your approval. A person always decides.
- Good Mongolian transcription. The automatic text can be wrong, so the factory marks it as low trust.
- Publishing. The factory does not post anything.

## Every evening

At 18:00 the factory writes a short daily review. It lists what is stuck, what worked and what it needs from you.
