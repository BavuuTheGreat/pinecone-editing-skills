# Editing rulebook v1 (testimonial)

Set by the Editing manager, benchmarked on 5 Pinecone seated-testimonial reels
(DfEm-d-iLUz, De_gAILE-kX, DbSWjRPjlsR, DbVDbKTjTty, DbpRFI8D0D3), approved in review 2026-11-12.

| Area | Rule |
|---|---|
| Voice | Student only. No interviewer audio anywhere. |
| Endings | Every answer ends on a finished sentence. Cuts land in breaths (quietest 40 ms). |
| Order | intro → q1 → q2 → q3 → q4. A question without a complete answer is skipped (no card). |
| Cuts | Hard cuts only. No blur, bloom or zoom transitions. |
| Cards | Charcoal grid card, question typed on letter by letter, real keyboard sound per letter. One card per question even when the answer has several pieces. |
| Card texts | q1 Яагаад Pinecone-д сурахаар болсон бэ? · q2 Одоо хамгийн сорилттой зүйл юу байна вэ? · q3 Одоо хамгийн гоё зүйл юу байна вэ? · q4 Сурах гэж буй хүмүүст ямар зөвлөгөө өгөх вэ? |
| Name title | Bold condensed name over the intro, kicker `PINECONE BOOTCAMP · СУРАГЧ` 42 px above. One line, `title_scale` 0.8 for 9+ letters, 0.62–0.75 for hyphenated long names. Ө and Ү must render in the title font. |
| Captions | GIP 57.5 px, white, centred, baseline y 1606. No line where the student says their own name. Corrected words and punctuation. |
| Music | "Funkorama" (Kevin MacLeod, CC BY 4.0), constant bed, no ducking, speech ~16.5 dB above it. |
| Loudness | -14.5 LUFS integrated, true peak ≤ -1 dBTP. |
| Brand | Soft tan Pinecone mark top-centre on clips and cards. |
| End | Hard cut from the last answer into the 10 s end card (`assets/end_card_9x16.mp4`), no corner logo over it. |
