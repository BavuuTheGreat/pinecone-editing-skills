# Testimonial / seated interview

Students (or a guest) seated in the studio answer set questions. Pick it for bootcamp student stories.

**Status:** Ready (review-approved 2026-11-12) · **Made by:** `testimonial-reel` · **Audit:** 8 reels, median 13.5K organic, 0.51%, 60-185 s, 4 cuts/min
**Examples:** instagram.com/reel/DfEm-d-iLUz, /reel/De_gAILE-kX, /reel/DbpRFI8D0D3

## Signals
- One person seated (sofa or desk), lav or handheld mic, interviewer off camera
- Answers to the standard questions (why Pinecone, hardest, best, advice)

## Need from you
- ★ Folder, one file per student · ★ each name spelled exactly

## Style
The full rulebook is `testimonial-reel/references/rulebook.md` (approved; do not change):
name title over the intro, 4 typed question cards with key sounds, student voice only, every answer ends
on a finished sentence, GIP captions without the name line, Funkorama bed 16.5 dB under speech, end card.
