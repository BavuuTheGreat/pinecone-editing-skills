# Podcast clip

A 30-60 s moment cut from a Pinecone podcast episode. Pick it for long-form talk with headphones and mics.

**Status:** Ready · **Made by:** `podcast-clipper` + `brand-templates` · **Audit:** 30 reels, median 10.1K organic, 0.90% (Oct), source clips 65-165 s, 3 cuts/min
**Examples:** instagram.com/reel/DbqFv2Fzd1L (title bar), /reel/DdIvbNqjtfz, /reel/DdGbVDQDQHP

## Signals
- Two people with headphones and podcast mics, 16:9 episode recording, long unbroken talk

## Need from you
- ★ Episode file or URL · ★ show name + episode number · optional: how many clips

## Style
| Part | Rule |
|---|---|
| Length | **30-60 s** (our median 100 s clips under-performed: 5 of the bottom 5 in Oct) |
| Structure | Start on the hook sentence (a claim, number or question), one idea, end on a finished sentence |
| Pace | Reframe to whoever speaks; 3-6 cuts/min |
| Captions | `WordCaptions`, word by word, active word highlighted |
| Graphics | Hook line as title for the first 3 s; podcast title bar with show + episode |
| Music | None under talk (the episode audio carries it) |
| End | `EndCard` naming the full episode, then the Pinecone end card |
